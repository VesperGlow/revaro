# 2026-09-22～23：Rust 迁移后整体回归与修复

## 范围与基线

本轮检查使用迁移前 `3a18bde` 的 Go + Vue + Rust data-plane 实例，对照当前
Rust 后端与 Leptos/WASM 前端。两个版本使用独立临时数据库和对象目录；真实
EPUB 检查另设一组隔离实例，避免密码修改、回收站等测试相互干扰。未操作生产数据。
当前代码基线为 `00d7541` 加本轮工作区修复，未自动提交或部署到生产。
收尾时已停止本轮启动的临时实例，保留隔离数据库、对象目录、构建产物及测试日志供复查。

保留已经确认的产品决定：不恢复侧栏、媒体库视图或列表视图；不恢复旧版
`/read/{id}` 刷新后不能重新打开阅读器的路由缺陷。

## 已修复

| 问题 | 原因与修复 | 回归证据 |
| --- | --- | --- |
| 音频进度条宽度异常 | 迁移遗漏 `FullBleedProgress` 的组件样式，原生 range 回落到默认宽度。补齐轨道、缓冲、滑块、章节标记、提示、焦点及触控层，并纳入样式清单。 | `rust-media-parity-ui`：1440/390/320 宽度、展开侧面板、点击/拖动/键盘定位。 |
| 清空回收站按钮样式遗漏 | 补齐危险操作颜色、40px 高度和禁用状态。 | `rust-responsive-layout-reference-parity`。 |
| 手机点击选择按钮中心误打开文件 | 按钮的三角形 `clip-path` 同时裁剪命中区域，触摸坐标取整后穿透到卡片。触屏改为完整按钮命中区，三角形移到无交互的装饰层。 | `rust-file-card-interaction-reference-parity`：真实 `tap()` 选择与取消，而非鼠标 `click()`；修复前打开 editor，修复后只切换选择。 |
| 关闭音视频预览后迟到响应触发 WASM panic | 元数据和进度读取仍访问已销毁的响应式状态；改为随组件销毁取消的读取任务。持久化进度写入不取消。 | 延迟 metadata/progress，关闭再释放响应；修复前 `pageerror: unreachable`，修复后无异常且可打开其他预览。 |
| 关闭目录选择器或退出登录后迟到请求触发 panic | 请求序号本身可能已销毁；用可失败读取检查当前请求，并在回退根目录之前检查组件是否仍有效。 | 延迟 picker、folder、trash 请求后关闭/退出登录。 |
| 阅读器关闭时的异步崩溃 | 开书读取随组件销毁取消；翻页动画、目录跳转、窗口加载及同步在异步等待后检查关闭状态，避免访问已销毁的 DOM 引用。 | 延迟 book/manifest/chunk、翻页动画中关闭、等待远端目录章节时关闭，5 项回归。 |
| 旧文档读取覆盖新草稿 | 新建文档未开始新的编辑会话；增加会话序号，并忽略已关闭会话的读取结果。 | 旧 GET 挂起，关闭后新建并输入，再释放旧响应。 |
| 保存期间继续输入被误标为已保存 | 成功回调把当前输入当作已保存内容；改为记录提交时的内容快照，保留后续输入的未保存状态。 | 连续输入两版内容，验证 dirty 标记及两次 PUT 的实际内容。 |
| 新建文档创建期间仍可修改即将失效的文件名 | 创建成功会以服务端文件名切换到现有文档，期间改名会被覆盖。提交期间锁定文件名，正文仍可编辑，并保留后续正文的 dirty 状态。 | 新建文档的延迟 POST 回归。 |
| 已关闭编辑器的保存结果修改新草稿 | 保存结果缺少会话校验；不再修改新编辑会话，仅在原目录仍为当前目录时触发刷新。 | 保存挂起，关闭并另建草稿，释放旧保存响应。 |
| 分享弹窗重开后的状态串线 | 读取、创建、重生成、撤销缺少弹窗会话校验；旧响应可覆盖当前链接或关闭新状态。新增会话序号与打开状态检查。 | 四类迟到响应均有重开回归，包括确认按钮恢复可用。 |
| 后台上传完成打断目录导航 | 导航成功前 `current_id` 仍指向原目录，上传完成的延迟刷新会覆盖正在进行的跳转。记录加载中的目标，上传和解压任务的后台刷新不得抢占跨目录或进入回收站的导航。 | 两项延迟导航回归：上传完成时原目录刷新次数修复前为 1、修复后为 0，目标页正常打开。 |
| 干净构建环境缺少 ZIP deflate 支持 | libarchive 编译时未安装 zlib 开发依赖可能静默缺少 deflate 解码。CI 显式安装 `zlib1g-dev`；Dockerfile 原已包含，无需修改。 | 安装依赖并重新编译 libarchive 后，原生解压测试及真实归档浏览器对照通过。 |

编辑器、分享会话竞争及后台刷新导航竞争也属于本轮发现的用户路径缺陷，不据此声称每一项都是
Rust 独有回退。修复保留正常交互，只隔离失效会话与尚未保存的内容。

## 测试维护

- 阅读流专用 Playwright 配置支持 `PLAYWRIGHT_EXECUTABLE_PATH`，与主配置一致。
- L2 缓存测试先关闭阅读器再刷新，避免把新版正确恢复深链误判为卡片无法点击；
  仍检查重开零 chunk 请求及 manifest 版本升级后的缓存失效。
- 编辑器文件 metadata 测试区分旧版列表与新版方块：都验证保存后大小及内容更新，
  仅在显示日期的旧版列表检查本地时间，不向新版重新添加已移除的列表信息。
- 本地归档测试补装 `bzip2`、`xz-utils`、`zstd`、`p7zip-full`，环境缺项不计入产品缺陷。
- 内容头排除已移除的视图切换按钮；工具栏以组件内部坐标比较，长文件名检查实际
  截断与视口边界，不再要求与旧侧栏占据空间时的绝对尺寸/位置相同。
- 音频恢复边界检查实际设置的 seek 值，避免自动播放跨越整数秒导致误报；缩略图
  错误测试强制新 URL，避免已经解码的网格缩略图绕过故障注入。
- 阅读器遮罩点击避开旧版侧栏在屏幕中部的高层级入口，并等待目录动画结束；未在
  新版恢复该旧版遮挡。上传恢复直接检查服务端仍为 pending，避免依赖被路由拦截的
  请求在页面刷新时是否发出 Playwright `requestfailed` 事件。
- 文件夹最终结构对照先等待旧版上传后刷新完成。全量检查的最后一项失败发生于旧版：
  其 250ms 延迟刷新打断目录导航；新版另用故障注入测试复现并修复这类竞争，未修改旧版代码。
