# Revaro 修复与功能交付 · 2026-10-02

本次依据 [初次扫描报告](code-review-2026-10-02.md) 修复确认的缺陷，并按确认的范围实现搜索、分享到期、版本历史及相关基础能力。报告中的原始复现结论保留为历史快照。

## 已修复的缺陷

| 问题 | 实现与验证 |
|---|---|
| 随机初始密码进入日志、缺少凭据文件 | 提交密码哈希前写入并同步 0600 JSON 凭据文件；初始化中断后复用该文件。日志及登录页指向文件。单测和真实进程启动验证权限、登录及日志无明文密码。 |
| EPUB 副本图片绑定原文件 ID | 共享解析及持久 flow 使用中性资产占位地址，发送 chunk 时绑定当前文件 ID；flow 格式升级至 v5。回归覆盖原书永久删除及重新创建服务器状态后的图片读取。 |
| 分享并发许可过早释放 | 将许可放入 HTTP body 流，直到 EOF/断开连接才释放。真实 TCP 测试保持 8 个 128 MiB 下载不读取，第 9 个返回 429，断开后许可恢复。 |
| 刷新后上传“重试”只改状态 | 等待原文件时标记 waiting_input/reselect_file；用户手势直接打开文件选择器，核对名称和大小，沿用已有会话与分片。实际传输才进入 running；失败返回 failed，重试计数在开始时更新。浏览器回归核验 17 MiB 续传和最终字节，以及取消操作。 |
| 负数保留时间被当成零 | 统一拒绝负值及带空白的负值；明确允许的零值保留现有语义。URL 使用正式解析、规范化 Origin，并拒绝凭据、路径、查询及片段。 |
| 并发移动目录可能形成循环 | 验证目标、检查后代及更新在 Immediate SQLite 事务内完成。并发 A→B / B→A 回归确认只允许一项成功。 |

## 新能力

- 文件名包含搜索：当前目录或全部目录，支持名称、大小、修改时间的升降序；API 每批最多 200 项，主界面单页连续滚动，每批追加 100 项，保留已有卡片和选择状态。顶栏默认只显示圆形 SVG 放大镜，从按钮原位向左展开为单一浅色圆角搜索控件，内部依次为放大镜、输入、范围和 ×；桌面及手机均固定右侧其他按钮的位置。Enter 搜索，× / Esc 收起，不提供独立搜索按钮。范围使用自定义二状态切换，按钮显示当前文件夹或全部文件夹，下方紧贴带极淡边框、轻微阴影的圆角菜单，仅显示另一个可切换的范围，hover 使用浅蓝灰背景。范围按钮保持 14px；鼠标聚焦无边框，键盘 Tab 聚焦仅使用轻量 focus-visible 样式。点击搜索外部收起，点击内部仅关闭范围选项；保留输入及范围选择。排序位于新建文档左侧并对齐，使用紧凑 split button，左侧文字居中、左右等距且无小下箭头，点击展开仅含名称、大小、时间的菜单，右侧较大的 ↑ / ↓ 独立反转方向，左右以浅分隔线区分。选择当前字段不会反转方向；切换字段默认名称及大小升序、时间降序。窄屏沿用紧凑的新建菜单。
- 分享有效期：默认界面为 7 天，可选 1 小时、1 天、30 天或永久；API 支持 1 秒至 365 天。访问时检查到期；账户页可分页查看和撤销链接。旧永久链接继续有效。
- 文本版本：保存前快照，最多保留 20 个历史版本；可以查看和按当前 ETag 恢复，恢复前也保存当前内容。维护扫描和对象清理保护历史引用，永久删除文件会清理历史。
- 目录递归复制：同一事务完成，保留结构和共享原对象引用，最多 5,000 项，拒绝复制进自身及后代。
- 目录 ZIP：保留路径与空目录，过滤不安全的路径组件，最多 1,000 个文件、5,000 个节点、128 层、1 TiB；客户端下载关闭后生成器停止。
- 工作预算：阅读解析/flow 构建共用 2 个全局许可，ZIP 生成共用 2 个；blocking 工作持有许可，避免 HTTP 请求取消后提前释放。
- 上传保护：可配置无进展/总超时，超时清理临时内容；创建会话、接收文件/分片、合并前检查磁盘可用空间和保留余量。
- 离线维护：`backup`、`restore`、`reset-admin` 接入二进制；与服务共享进程锁。备份数据库快照、完整对象及校验清单，复制时保留对象修改时间；恢复验证 SHA-256 与 SQLite 完整性，并要求空目标。管理员恢复文件为 0600，不输出明文密码。
- 浏览器缓存：32 个 manifest、256 个 chunk、32 MiB、7 天有效期；串行容量准入，清理旧 cache namespace，登出/改密码清理，账户页有清理入口。
- 运维视图：账户页显示磁盘余量、任务数量、缓存统计、维护连续失败/运行状态及可用工作许可。
- 批量操作：恢复和永久删除继续处理其他项目，报告成功/失败数量与项目错误；恢复失败项保留选择，移动/复制保留原有成功/失败计数。
- 模块分离：分享管理独立于 file_routes；搜索、历史、运行统计及离线维护各有独立后端模块，历史/管理面板有独立前端组件。保留历史 DTO 空值兼容与既有路由，避免破坏已有调用方。
