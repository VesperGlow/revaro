# 阅读、音乐与图库：第一版

2026-10-03，基于原有 Rust / Leptos 应用完成的可运行版本。

## 已实现

- 首页：继续阅读、最近播放和最近图片；删除三个重复概览入口、宣传 Hero、插画和英文装饰标题。媒体页直接从筛选和集合操作开始，保持浅色、低对比度界面。
- 阅读：EPUB/TXT 全局书库、封面、收藏、书架；复用原阅读器的目录、排版、主题和位置恢复，保留 `/read/{id}` 深链。
- 音乐：歌曲列表、收藏、歌单、播放全部；一个持续挂载的 audio 元素，切换到阅读/图库时继续播放；队列、上一首/下一首、随机、顺序/列表循环/单曲循环、进度、音量；阅读时收成顶部小控件，手机导航收起，避免遮挡阅读工具。
- 图库：图片墙、收藏、相册；复用大图缩放/拖动/缩略图条，浏览接近分页末尾时预加载下一批。原图下载及移动/复制接入现有文件工具。
- 数据：SQLite 第 005 号迁移回填既有内容，触发器同步上传提交和重命名后的分类；收藏、最近使用和集合关系独立保存。集合只引用文件 ID，移出集合不删除原文件。回收站和永久删除沿用原生命周期。
- 文件工具：保留上传、分片续传、目录、下载、分享、编辑、历史、视频、回收站、任务、账户和 TOTP。
- 统一顶栏：五个页面复用现有 `AppTopbar`，通过 `TopbarActions` 注入文件工具。左侧 logo 回首页，中间五项 SVG 图标导航以整个顶栏为参照严格水平居中，激活下划线与图标中心重合；保留可访问名称、title、激活下划线和浅色反馈；右侧入口统一 44×44px 点击区域并垂直居中，账户名称移入头像提示；图标入口包括：模块搜索、新建、上传、任务、回收站和账户；删除文件页第二层顶栏和内容页自写 Header。移动端统一在 850px 切换为工具菜单与五项底部导航，导航 active、路由和历史行为共用。
- 搜索与筛选：阅读、音乐、图库和文件统一使用顶栏搜索，原地向左展开，按页面切换 placeholder 并调用原查询回调；文件按目录自动确定范围：根目录搜全盘，文件夹内只搜直接子项，不再保留范围选择器，模块切换不串用内容查询。删除页面内搜索框，收藏改成带 `aria-pressed` 的爱心 SVG，书架/歌单/相册下拉复用 `ActionMenu`，不使用原生 select。搜索关闭放在点击处理之后，避免顶栏收缩让导航丢失点击。展开搜索默认约 208px，按输入文字实际宽度增长，清空后缩短；宽度受视口和右侧可用空间限制，右侧工具保持原位；851–1150px 下编辑搜索时临时收起中央导航，关闭搜索后恢复原中心，保留 logo 和右侧操作入口。
- 文件操作：新建与上传使用从原媒体预览提取的同一个 `ActionMenu`；媒体预览与集合筛选同步复用该组件；统一圆角、浅边框和轻阴影。菜单、文件排序和任务中心复用同一 `anchor_popover` 定位函数：默认从入口下方 8px 水平居中展开，靠近视口边缘时才最小避让，底部空间不足时向上展开。窗口缩放、滚动和弹层内容尺寸变化会重新定位；观察器与动画帧随组件卸载清理。窄屏任务面板使用实际账户工具入口作 anchor，不再使用硬编码偏移。菜单提供新建文档/文件夹、上传文件/文件夹，支持外部点击、焦点离开关闭和 Escape 返回触发按钮。文件内容区只保留路径、项目摘要和排序；空列表也不重复添加操作按钮。全局操作保存到根目录，文件页操作保存到当前目录。
- 账户：状态摘要、刷新状态、清理阅读缓存和公开链接直接展示，无折叠或诊断 JSON。状态获取使用固定高度的 skeleton，成功淡入、失败显示“状态获取失败”，后续按钮与标题位置不变；尊重减少动画设置。空链接列表只显示“暂无公开链接”，实际有前后页时才显示分页。

内容库每批默认 60 项，由服务端在全库中查询类别、名称、收藏及集合；音乐“播放全部”会取完整当前查询，图库大图浏览可以继续加载后续分页。

## 本地实例

```sh
./scripts/preview.sh
python3 scripts/seed-preview.py  # 可选；已有内容时跳过
```

- 地址：`http://localhost:8081`
- 账户：`admin` / `revaro-preview-2026`
- 数据：`data/content-preview/database`、`objects`、`caches`
- 前端：`dist/content-preview-web`
- 支持 `PREVIEW_PORT`、`PREVIEW_ROOT`、`PREVIEW_PASSWORD`；构建完成后用 `--no-build` 启动。

已导入 3 本原创演示 EPUB、3 段 45 秒合成音频、8 张程序绘制图片，以及书架、歌单、相册和收藏。演示资产通过正常上传接口生成，均可按普通文件删除。

## 本版边界与下一步

当前展示名主要来自文件名；作者、歌手、专辑和 EXIF 资料、日期分组、细化阅读状态/进度展示、批注尚未实现。音乐播放进度会同步，但页面刷新后不会自动恢复队列或续播。集合目前支持创建、加入/移出、删除，重命名和手动排序留到下一版。筛选没有编码到 URL。

本版未增加 PDF 阅读、音乐转码或多人独立内容库。音视频能否播放取决于浏览器对原格式的支持。
