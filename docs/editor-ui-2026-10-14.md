# Revaro 文本编辑器交互优化（2026-10-14）

沿用现有网盘的设计变量、按钮、正文和 Markdown 样式，范围限定为文本编辑器、版本历史及其回归测试。服务端接口、持久化结构、历史保留数量与 ETag 冲突规则沿用现有实现。

## 版本历史与文档状态

- 桌面版本历史为编辑器内 340px 的右侧栏。历史列表有独立滚动区，移除旧的 45vh 高度限制、额外内边距及重复历史样式，侧栏填满可用正文高度；打开和查看历史均不增加遮罩或新的历史弹窗。
- 查看操作在原正文区域显示可选择、可复制的只读文本，标注版本时间，并提供“返回当前文档”。查看期间禁用普通保存及编辑模式切换，快捷键也不能把历史内容当作当前文件保存。
- 当前文本框和 Markdown 预览保持挂载；进入历史前记录滚动位置、选区起止与选区方向，返回或关闭历史时恢复。历史文本不写入当前内容信号或本机草稿。
- 850px 及以下使用编辑器内部的内容/历史列表切换，查看后自动切到只读内容。关闭历史及返回当前文档均保留未保存修改。
- 桌面侧栏打开时可以继续编辑当前文档。普通保存成功后，历史列表跟随 ETag 更新，不需要关闭后重开。
- 恢复沿用 `ActionDialog` 二次确认；仅确认时出现确认层。底层编辑器在确认期间禁止交互，取消后焦点回到发起恢复的按钮，恢复请求等待期间不能编辑。恢复 API 继续保存当前服务器版本，并以 ETag 防止覆盖其他设备的新内容；未保存修改仍需先保存。
- Esc 优先退出历史预览，再关闭历史侧栏；编辑器原有未保存修改确认保留。
- 关闭历史后抵达的旧内容请求不再更改正文，关闭编辑器后尚未执行的布局回调也会检查组件是否仍存在。

## 鼠标指针、插入光标与其他交互

代码审查仅发现视频播放器使用 `cursor: none`，选择器限定于视频播放容器；未发现编辑器自身隐藏指针、调用 Pointer Lock 或设置透明层接管正文鼠标事件。

编辑器明确设置默认指针，文本框、只读历史及可选择的 Markdown 文本使用文本选择指针，按钮和链接使用 pointer。这样即使上层容器带有隐藏指针样式，也不会继承到编辑器。正文和历史文本分别有明确的 `caret-color`，选区使用现有主题变量；键盘焦点使用不挤占布局的内描边，切换按钮补齐有效的 ARIA 状态和悬停反馈。

鼠标指针与文本插入光标分开验证：自动测试检查移动后的 `elementFromPoint` 命中、cursor、输入焦点、文字选区及 textarea caret 配色。只读文本不能输入，Markdown 展示区域不被当作可编辑输入框。没有添加通过重建输入框、切换焦点或不断切换 cursor 来干预输入的逻辑。无头浏览器无法直接观察操作系统绘制的真实鼠标指针，因此未将键入期间可能出现的原生指针隐藏判定为编辑器故障，也不宣称已经复现特定操作系统的原生行为。

编辑、分栏、预览与历史查看各自使用有边界的滚动区域；普通保存快捷键与工具栏禁用状态一致。Markdown 内容只在需要展示时渲染，历史状态判断避免反复复制大段文本。

- 现有 `cargo xtask build`：release 前端与服务端完整构建。

- 新增 `editor-interactions.spec.ts`：桌面/手机 × 深浅主题，验证同一文本框节点、滚动、反向选区、只读内容、快捷键、唯一编辑器遮罩、侧栏保存后刷新、各模式指针命中、迟到请求及 ETag 冲突。
