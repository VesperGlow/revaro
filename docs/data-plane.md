# Go / Rust responsibilities

Go owns SQLite, authentication, logical files, shares and the public API. Local object storage uses `APP_DATA_DIR/objects`, with UUID keys under `blobs/`. Go's `os.Root` confines reads and writes to this directory. Streaming writes use a temporary file, size validation, fsync and atomic rename. Immutable derived objects use a create-only hard link.

Go serves native HTTP Range responses for downloads and playback. Upload URLs are authenticated same-origin routes; large uploads use persistent local parts, validated ETags and atomic assembly. No presigning, public object endpoint or S3 file client remains.

Rust listens only on loopback and requires the per-process bearer token generated by Go. Its media operations read local files: probe, thumbnail, embedded cover and subtitle extraction. Archive extraction reads the same local store and reports progress to Go. Rust does not own SQLite metadata transactions.

S3 is isolated in `data-plane/src/backup.rs`. Its private API accepts only database snapshot keys under `revaro-backups/database/`: upload, list and retention deletion. It cannot read or write ordinary S3 files. The Go backup scheduler uses a separate `DatabaseBackup` interface, never the local object manager.

## Commit and cleanup

The application exposes a newly uploaded file only after its bytes, size, integrity hash and SQLite transaction are committed. Upload cancellation and completion are serialized. Metadata failures retain enough state to retry; unreferenced blobs are removed after the grace period. Shared UUID references remain alive while any file or retained audio metadata references them.

The server owns worker cancellation and waits for workers during shutdown. Tasks include uploads, archive extraction and subtitle preparation. Reader caches are kept under the configured work directory; durable reader objects and thumbnails are local.

See [local-storage-migration.md](local-storage-migration.md) for upgrades and rollback. Historical schema migrations remain to support existing databases; retired download and conversion records are not resumed.
