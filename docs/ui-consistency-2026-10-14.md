# Revaro UI 一致性审查与修复（2026-10-14）

后续编辑器优化已将这里记录的版本历史弹窗替换为编辑器内部侧栏，当前实现与验证见 [编辑器交互优化记录](editor-ui-2026-10-14.md)。

以现有网盘的草绿色主色、设计变量和组件为基准。审查范围包括登录及启动页、首页、四类内容库、文件与回收站、顶栏与菜单、文件操作弹窗、目录选择器、文本编辑器、图片预览、音视频播放器、阅读器、账户及安全设置和公开文件加载页。没有调整后端接口、数据结构、版本保留数量、ETag 检查或文件业务规则。

## 发现与修复

| 问题 | 修复 |
| --- | --- |
| 版本历史直接插入编辑器网格，挤占正文空间、出现隐式网格行和滚动混杂 | 复用 `DialogBackdrop` 和 `.modal`，独立覆盖弹窗；头尾固定，列表及只读预览各自滚动；下层编辑器使用 `inert` |
| 版本历史使用无样式按钮、完整 ISO 时间和原始字节数 | 复用 `.secondary`、本地时区 `format_date` 和 `format_size`；紧凑列表明确标注查看、恢复和只读预览 |
| 恢复按钮立即提交，缺少确认 | 复用 `ActionDialog`，确认时间及当前内容会保留；取消不写入，处理中禁用操作，保留未保存修改保护和原有冲突检查 |
| 历史列表无加载失败重试入口 | 增加统一错误提示及重试，加载、空列表与预览失败采用独立状态 |
| 草稿提示和错误提示占用编辑器错误的网格行，保存错误在手机端被隐藏 | 将提示收纳到专用通知行，正文始终占据剩余空间；保存错误在全部屏幕可见，统一草稿操作按钮和错误状态配色 |
| 手机编辑器按钮与标题争抢横向空间，动态视口高度覆盖顺序不正确 | 手机标题、操作和视图切换采用明确网格行，修正 `100dvh` 高度及安全区；历史预览改为上下分区 |
| 部分重试、推荐、普通按钮及表单控件沿用浏览器默认外观 | 在现有 `ui.css` 中补齐零优先级共用控件样式，专用菜单、卡片、播放器及阅读器规则继续决定其形态；播放进度重试使用现有按钮 |
| 共用弹窗缺少统一焦点进入、循环和返回，以及 Esc 关闭行为 | 共用弹窗处理焦点和键盘操作；嵌套弹窗先关闭当前层；保留原有仅点击背景关闭和拖动选择保护 |
| 共用确认弹窗缺少高度边界，长错误提示可能与布局错位 | 设置视口内最大高度和独立滚动；修正错误提示跨列、长文字换行及操作区换行 |
| 确认弹窗、登录表单、目录选择器和编辑器等写死白色背景 | 改用现有 surface、文字和状态变量；清理确认弹窗重复 CSS |
| 网盘整体无深色变量，深色主题控件出现白底、低对比文字 | 在唯一设计变量块添加系统深色映射；按钮前景使用配套变量，目录、堆叠徽标和播放器控件同步适配；登录插画保留深色草绿背景与可读的浅色文字 |
| 阅读器纸张主题和操作系统原生控件主题可能不同 | 纸张和夜间阅读器显式设置 `color-scheme`；纸张主题保留原有草绿色强调色 |
| 启动页深色环境出现亮底闪烁，公开文件加载页为无样式文字 | 启动占位及浏览器主题色适配系统主题；公开文件加载页复用现有 splash、标志、spinner 和样式入口 |

媒体原图、封面上的渐变白字、视频观看背景和验证二维码保留适合内容展示的对比度。原有阅读器纸张/夜间偏好保持独立；网盘页面随操作系统切换深浅主题。

## 验证

- `cargo xtask check`：格式检查、Clippy、工作区全量测试和 WASM 全目标类型检查。
- `cargo xtask build`：完整 release 前端及服务端构建。
- Playwright：现有账户、弹窗关闭、文件操作、版本恢复、草稿恢复，以及播放器、阅读器、顶栏和内容库回归。
- 新增 `tests/e2e/ui-consistency.spec.ts`：桌面/320px 手机 × 浅色/深色；20 条历史、长预览、本地时区、滚动边界、取消与确认、未保存保护、焦点循环、嵌套 Esc、表单与主题一致性；音频控件对比度及阅读器独立主题。

执行结果：`cargo xtask check` 全部通过（554 项 Rust 测试）；`cargo xtask build` 完整 release 构建通过；两个独立实例上的 Playwright 回归分别通过 53 项及 52 项，合计 105 项。新增的 12 项覆盖桌面/手机与深浅主题的四种组合，使用 `Asia/Shanghai` 核对浏览器本地时间。浏览器为 `/usr/bin/chromium`。

浏览器测试使用独立临时数据库及对象目录，本地预览继续使用 `data/content-preview/` 的原有数据库、文件对象和缓存。已将本地实例切换到新 release 服务端并更新前端，地址为 `http://localhost:8081`；生产构建与本地预览的 JS、WASM 和 CSS hash 一致。实际登录验证手机端深浅主题均无页面异常、横向溢出；登录插画的正文和标题另行检查了深浅主题文字对比度。

本地效果截图保存在 `.demo-shots/`（忽略提交的审查产物）：`ui-consistency-desktop-light.png`、`ui-consistency-desktop-dark.png`、`ui-consistency-mobile-light.png`、`ui-consistency-mobile-dark.png` 和 `ui-consistency-login-dark.png`。

回归期间发现的嵌套弹窗手势状态残留已修复，最终手机端弹窗关闭测试通过。临时测试服务已停止，本地预览继续运行。
